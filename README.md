# Lilys 🌸🪷

*Blooming in the terminal, line by line.*  
Terminal-based Python ASCII & ANSI art animation of blooming lilies — as seen on TikTok.  
*Terminal üzerinde çiçek açan zambakların Python ASCII & ANSI animasyonu.*

---

### 🚀 How to Run / Nasıl Çalıştırılır?

1. Download `lilys.py` (or copy the code). / `lilys.py` dosyasını indirin (veya kodu kopyalayın).
2. Open a terminal that supports ANSI colors (VS Code, Windows Terminal, macOS Terminal, or Termux). / Renkli çıktıyı (ANSI) destekleyen bir terminal açın.
3. Run the script in the file's directory / Dosyanın bulunduğu klasörde şu komutu çalıştırın:

```bash
python lilies.py
```
